## 1. Glossary of relevant terminology used throughout this project:
| Term               | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|--------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Core Terminology**                                                                                                                                                                                 | 
| T4, IW5, S1...     | Codenames for different Call of Duty games mainly used in developmental environments. It starts with the initials of the development studio (T for Treyarch, IW for Infinity Ward, S for Sledgehammer), the only exception is H1 and H2, which are used for MWR and MW2CR respectively (see definition on abbreviations below) as they were primarily made by Raven Software and High Moon Studios.                                                                                                                                                                                                                 |
| WAW, Bo1, MW2...   | Abbreviations for different games. Usually just the first letter of each word in the game's title followed by the number. If there is no number, like for Infinite Warfare or Black Ops Cold War, then the initials are used, so the two games are referred to as IW and BOCW respectively. For games with identical titles (like Modern Warfare 3 from 2010 and 2023), the same abbreviation is used but in different contexts.                                                                                                                                                                                                                                                                                                                                                              |
| **Game Client Terminology**                                                                                                                                                                                 | 
| Clients            | Over the years, each game began experiencing issues after its developmental lifecycle was over. These issues include lack of anti-cheat measures, security risks, and inactive servers. This led to members of the community to design different environments for the games to be ran through called clients. A few of the most well known clients will be listed below.                                                                                                                                                                                                                                            |
| Plutonium          | The most used game client out of all of them, designed for T4, IW5, T5, and T6 as it is required for all competitive submissions under ZWR rules. The client provides many anti-cheat options through being able to detect loading unlegit scripts into the game and other cheating methods. It also has many quality of life features like pause_hard, allowing players to fully pause their games without worries of erroring.                                                                                                                                                                                    |
| BGamer             | A client specifically designed for T5 (Black Ops). It was the predecessor to Plutonium and the first client to allow offline multiplayer matches on BO1 without reliance on game servers. However, BGamer has a bug where it overhauls the engine to remove the Box Error (explained further down below), causing zombies to no longer spawn after the set amount of box hits. This caused controversy amongst the community, which resulted in Plutonium being mandated on ZWR. However, it has the most similar file structure and mod tool compatibility as the Steam version of the game compared to Plutonium. |
| T7 Patch           | The T7 Patch is not a client, but it is essential in understanding the history of Boiii. It was created due to remote attacks on people's PCs caused by running the Steam version of Black Ops 3. It did not add anything additional and is still allowed under some rulesets on ZWR                                                                                                                                                                                                                                                                                                                                |
| Boiii              | Boiii is the current client for Black Ops 3 which is mandated for most ZWR rulesets. Just like the T7 patch, it provides security for players on PC. However, it also provides anti-cheat measures and the ability to locally host multiplayer games using VPNs.                                                                                                                                                                                                                                                                                                                                                    |
| Iw7                | Iw7 is the client for Infinite Warfare, which uses the same codename. It is based on early versions of Boiii and is not allowed under current rulesets due to significant alterations in the game. It provides a good enough environment for modding and scripting however.                                                                                                                                                                                                                                                                                                                                         |
| Steam              | Steam is the native game launcher for all Call of Duty games on PC except BO4. It is the baseline for playing these games and remained so for a very long time. However, after development ended, many issues and vulnerabilities arose regarding Steam, which mandated the clients to be created. For games ran through steam, the terms "Steam Version", "Steam (game abbreviation)", or "Vanilla (game abbreviation)" are used.                                                                                                                                                                                  |
| Project BO4/SHIELD | Project BO4, formerly known as SHIELD, is the client for Black Ops 4. While it is currently in development, it has some of Plutonium's anti-cheat features while also allowing players to play offline, independent of native Battle.net servers which BO4 uses instead of steam. Project BO4 is also the only way to use custom textures in the game, which is the center of one of my CAS projects.                                                                                                                                                                                                               |
| **Error/Technical Terminology**                                                                                                                                                                                 | 
| Custom Camos       | Custom Camos are modified textuers on any zombies game. These include weapon camouflages, perk icons, and map retextures. Popular examples include [Bone-Crusher's animated Black Ops 1 camos](https://forum.plutonium.pw/topic/44479/animated-camos-for-all-weapons), or [The BO1 Megapack posted by RainingZombies](https://forum.plutonium.pw/topic/21640/zm-bo1-custom-camo-mega-pack-1000-camos-for-weapons-maps-skins-more). One of my CAS projects entails making similar projects on Black Ops 4 using the Project BO4 Client.                                                                              |
| Box Error          | Box Error is the common term used for the error caused by threads leaking and overflowing due to faulty code on WaW-BO3. The reason it is called Box Error, is because using the in-game mystery box leaks a thread after each use. [Here is a more detailed explanation by Furretcanwalk regarding the Box Error in general](https://youtu.be/papy0qzGtww?si=FMuoDkrEZ6mJyqa9&t=4772). [One cause of the Box Error is also explained here by Furret](https://youtu.be/papy0qzGtww?si=-h3GDLYRMvb_NOhx&t=17134)                                                                                                     |
| Reset              | Reset is an engine limitation on every call of duty game up until Black Ops 4. It is caused by the game taking a snapshot of all interactible objects, such as players, zombies, barricades, and quest items, known as entities over and over until it overflows past the 32 bit integer limit. [A more detailed explanation by Furretcanwalk is available here](https://youtu.be/papy0qzGtww?si=YkzNXWzLOtZR02G9&t=1694)                                                                                                                                                                                           |
| Hashed (in regards to assets)     | When assets are compiled by the game, their names are usually encoded and changed so the machine can read them. When they are decompiled, they are usually shown as hexadecimal digits. It is possible to reverse engineer the hashed assets to find their original names in plain text. |
| Hashes (in regards to anti-cheat) | One anticheat command ran by game clients like Plutonium is Flashscripthashes, it displays what script is loaded in the game and its checksum (also called a hash). This is another hexadecimal digit that is used to monitor whether integral game files have been messed with.         |
| Dump                              | A dump refers to a set of extracted assets directly from the game. For example, with asset extraction tools like Recon and Saluki. Dumps are usually in .dds, .iwi, or .png.                                                                                                                                                       |
| Asset                             | An Asset is anything the game loads and uses in gameplay. This includes textures, sounds, and models.                                                                                                                                                                                                                                                                         |
| Patching RNG | RNG, which stands for Random Number Generation, is a term used to define randomness in games. For the context of COD Zombies, which is the game series that this project focuses on, there are a lot of crucial RNG elements such as what weapon is chosen by the mystery box or what perk is awarded when picking up a random perk power-up. These RNG elements are able to be manipulated in player's favor using external scripts and mods, this is called patching. Common examples include First Box Patches (explained below), Perk Patches, and Special Round Frequency patches. The allowance of these patches significantly varies depending on the rulesets and may not be the same in rules for the same game or the same category for different games. |
| Drop Cycles | Every map on every zombies game made by Treyarch, the power-ups dropped by zombies, often referred to as drops, are usually randomized with the drop cycle, where all the drops available are shuffled and need to all be granted to be given again. [A more detailed explanation by Furret is available here](https://youtu.be/papy0qzGtww?si=rz56RkpvhgC8HgW-&t=5050)
| **Mods Terminology**                                                                                                                                                                                |
| Ascendance by oJumpy | Ascendance is a family of mods created by Black Ops  3 player oJumpy. These mods are made mainly for aestethic purposes, allowing players to change different textures in the game like perk icons, camos, in-game characters, and many more assets to a pre-selected collection of different textures that are customly made or from different Call of Duty games that are not Black Ops 3. It also serves to provide error trackers and visually customize weapons that would not be customizable normally on the vanilla version of Black Ops 3. There are slight differences between different Ascendance mods, like for example, [The Base Version or Aestethic](https://steamcommunity.com/sharedfiles/filedetails/?id=3000417367) only contains things relating to aestethic changes like textures and camos while [4modderz](https://steamcommunity.com/sharedfiles/filedetails/?id=3006851410) allows players to patch their rng such as the first box on any map. Different versions of the mod are available for differing rulesets and categories and is allowed under current ZWR rulesets for all categories, provided the relevant version of the mod is used. |
| First Box Patching | First Box Patching, often referred to as First Box or FB, involves manipulating the mystery box, a buyable crate that gives the player a randomized weapon for 950 points, to give the player the desired weapons and items before it moves, since the box has a chance to move locations after being bought 4 times up to 9 times when it is guaranteed to move. This is used to acquire the necessary items quicker and to avoid Fire Sales, which are power-ups that can be dropped by zombies only after the box has moved locations which makes the box spawn in all locations and cost only 10 points for 30 seconds, in favor for more useful drops in the drop cycle. Examples of patches that include FB include [Ascendance 4modderz for Black Ops 3](https://steamcommunity.com/sharedfiles/filedetails/?id=3006851410)  and [B2OP for Black Ops 2](https://github.com/B2ORG/T6-B2OP-PATCH)|

| Saluki                            |  [Saluki](https://github.com/echo000/saluki-releases) is a software used to dump assets from various games by loading and/or opening package files. It allows the extraction and conversion of assets into different formats to be worked on or inspected. For more details, read the description on its GitHub Repository.                                                                                                                                                                                                                                                                                        |

## How to install camos on BO4 (only through the client)
1. Download either the release or whatever camo you want as a zip.
2. Unzip it and place it into your (game folder)/project-bo4/images folder, if it does not exist, then create one.
3. Load into BO4 through the client and you should see it there.
